# 개인정보와 코드 처리 경계

## 현재 상태

1–4단계는 브라우저에서만 파일을 읽고 분석하며 전송/DB 저장을 하지 않는다. 5단계에서 사용자가 명시적으로 동의해 `Analyze with AI`를 누른 경우에만, 정제된 입력을 로컬 개발 API가 Google Gemini로 전달한다. 인증은 아직 연결하지 않았으므로 Production에서는 Gemini 호출을 비활성화한다.

## 브라우저 경계

- 사용자가 명시적으로 선택한 폴더만 다룬다. 원본 소스는 브라우저 메모리에서만 처리하고 프로젝트 해제 시 참조를 정리한다.
- 원본을 localStorage, IndexedDB, DB, 서버 파일시스템에 영구 저장하지 않는다.
- .env 및 .env.* 실제 환경 파일, 개인키/인증서/자격증명 파일은 분석/전송 대상에서 제외한다. .env.example만 구조 확인용으로 허용하며 실제 값은 제거한다.
- 코드/JSON/Markdown에도 Secret이 있을 수 있다. 로컬에서 후보를 탐지한 뒤 근거/화면에는 값을 마스킹한다. 원문을 Secret 해시로 대체 저장하지도 않는다.
- 정규화된 상대 경로만 사용하며 절대 경로, 상위 경로 탈출, 중복/비정상 경로를 거부한다.

## 서버와 Gemini 경계

- 서버/Gemini에는 정제한 stack/file-count/coverage/점수 요약, 우선순위가 높은 제한된 Rule Issue, 관련 관계/스키마 필드, 최대 5개의 이슈 주변 짧은 코드 조각만 전달한다. 각 조각은 최대 2,000자이며 작은 파일 전체가 조각으로 전송되지 않도록 제외한다. 전체 payload는 48,000자, API body는 64 KiB로 제한하고 누락 범위를 AI coverage에 기록한다. 전송 내용/Google Gemini 외부 처리는 사용자의 동의 뒤 호출한다.
- AI 전송 동의는 프로젝트/세션 메모리에만 유지하며 프로젝트 변경 시 패널이 초기화된다. 사용자가 취소하면 브라우저 요청을 중단한다.
- 서버는 입력을 신뢰하지 않고 크기/형식/허용 필드/상대 경로/민감정보를 재검증한다. Gemini SDK 호출 직전에 Secret 후보를 다시 마스킹한다. 실패 시 원문을 오류에 포함하지 않는다.
- Gemini에는 필요한 최소 정보만 제공하고 Secret 후보를 전송 전에 마스킹한다. 탐지의 완전성을 보장하는 표현을 사용하지 않는다.
- GEMINI_API_KEY는 서버 전용이며 NEXT_PUBLIC_ 접두어, 클라이언트 번들, API 응답, 로그에 포함하지 않는다.
- 프로젝트 주석/README는 명령이 아닌 분석 데이터다. 사용자 코드를 실행/eval/import하거나 scripts/설정/플러그인을 실행하지 않는다. 프로젝트 URL로 서버 요청도 하지 않는다.
- AI 출력은 Structured Output과 Zod로 검증한다. Issue ID, 파일 경로, 행은 요청에 포함된 참조만 통과시키며 잘못된 참조는 제거/부분 근거로 표시한다. UI는 React 텍스트 렌더링으로 출력하며 도구 실행 권한을 부여하지 않는다.
- 요청은 25초 제한, 429 및 일시적 5xx에 대해 최대 한 번 재시도한다. SDK 자체 재시도는 1회 시도로 제한한다. 애플리케이션은 전체 분산 rate limit을 제공하지 않는다. 현재 endpoint는 인증 전 개발 환경에서만 Gemini를 호출하고 Production에서는 건너뛴다.
- 전체 프롬프트/원본 응답은 DB/로그에 기록하지 않는다. 현재 단계에서는 audit 결과를 저장하는 DB가 없다.

## 저장 경계 (7단계)

허용: 소유자/프로젝트 메타데이터, 점수/버전/coverage/상태, 정제한 요약/Issue, 상대 위치, 짧은 마스킹 근거, 정제한 관계, 수정 제안, 해결 상태, 검사 날짜.

금지: 전체 프로젝트 소스, 실제 환경 값/Secret, 원본 파일 본문, 전체 Gemini prompt/response. AI 결과는 검증 후 필요한 필드만 저장한다.

요청 본문/코드/프롬프트/응답 덤프를 서버 로그나 에러 추적에 남기지 않는다. Supabase 공개 URL/anon 키는 RLS를 전제로 공개 설정이며 서버 비밀키와 구별한다. 모든 데이터는 Auth 소유권/RLS로 격리한다.

원본이 없으므로 이력에서 전체 코드를 복원할 수 없으며 재검사는 폴더 재선택이 필요하다. 감사 삭제는 관련 Issue/위치/관계를 함께 삭제한다. 외부 제공자 보관/백업 정책은 실제 연결 단계에서 확인하고 앱 삭제와 구분해 안내한다.
